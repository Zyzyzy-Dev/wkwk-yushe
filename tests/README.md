# Node 测试（维护者与 AI 阅读）

此目录仅包含开发验证代码，不参与插件运行，不需要部署后执行。根入口与 src 不得导入 tests。

在插件仓库根目录运行：

```sh
node --test
```

Node 自动发现本目录的 `.test.js` / `.test.mjs`。也可指定单个文件，例如 `node --test tests/api-manager.test.js`。

测试从 src 导入纯功能模块，覆盖预设、世界书、快照、API 数据处理和边界情况；目录结构测试检查相对资源引用及文件头说明。移动文件时同步调整测试 import，不能用复制旧运行文件的方式掩盖错误路径。

不要在包含用户材料、第三方参考项目的工作区父目录执行全局测试。测试只使用构造数据，禁止写入真实密钥或用户预设。浏览器／真实酒馆交互还需单独验证，Node 测试不代表实机端到端验证。
