# 预设更新编辑器

这是一个用于 SillyTavern OpenAI / Chat Completion 预设的对比和迁移插件。它可以同时载入旧版与新版预设，快速查看条目与正则差异，并将条目、正则或修改后的内容迁移到另一版本。

## 代码结构与隔离

插件使用原生 ES Module 拆分，并把完整工作区运行在独立 iframe document 中：

- `index.js`：唯一扩展入口，只安装宿主控制器。
- `src/host.js`：唯一允许接触酒馆主页面的模块；负责扩展菜单、iframe 外壳、preset-manager 调用、`PRESET_CHANGED` 订阅以及主题/输入法环境转发。
- `src/core.js`：不接触 DOM 的预设校验、顺序节点选择、正则配对与迁移、正文相似度、混合粒度 diff 和变量宏解析，以及保存回酒馆时的「当前活动预设判定 / 内存同步」纯逻辑。
- `src/ui/app.js`：iframe 内的状态、交互与渲染。
- `src/ui/bridge.js`：基于 `MessageChannel` 的请求/响应和事件通道。
- `src/snapshot.js`：设置快照的两层开关捕获、恢复计划和绑定优先级纯逻辑。
- `src/snapshot-resources.js`：世界书配置与正则开关的捕获、校验及稳定标识恢复。
- `src/worldbook-workbench.js`：完整世界书校验、条目配对、迁移、排序与预设转换的纯逻辑。
- `src/ui/worldbook-workbench.js` / `worldbook-workbench.css`：双世界书工作台；`worldbook-entry-editor.js` 提供编辑与差异查看，`worldbook-workbench-drag.js` 处理鼠标与触屏拖拽。
- `src/ui/snapshot-panel.js` / `snapshot-panel.css`：快照管理页面；持久化及常驻聊天监听由 `src/host.js` 执行。
- `src/ui/snapshot-editor.js` / `snapshot-editor.css`：独立快照草稿编辑页，创建、覆盖和另存不会立即应用设置。
- `src/ui/native-switch.css`：预设、世界书、正则与分组统一的原生滑钮样式。
- `src/ui/index.html` / `src/ui/style.css`：iframe 自己的 HTML 与完整基础样式。

本项目以 **SillyTavern 官方 Web 版为主目标**，同时对 **TauriTavern** 做可选适配：标准路径只使用 SillyTavern 的扩展加载器、`openai.js`、`preset-manager.js` 和事件总线；仅检测到 `window.__TAURITAVERN__` 时才动态加载 TauriTavern `layout-kit.js`，把同源 iframe 标记为 `ViewportHost` 并转发 IME 高度。Tauri 适配失败或超时不会阻塞标准 SillyTavern UI，普通浏览器继续使用 `visualViewport` 回退。

`manifest.json` 不再向酒馆主 document 加载插件 CSS。主页面及其他美化插件的选择器默认无法跨过 iframe 边界，插件样式也无法影响酒馆外部；宿主只保留一个菜单入口和 iframe 外壳。业务 UI 不直接读取酒馆全局对象、TauriTavern API 或主页面 DOM；`bridge.js` 仅校验同源父窗口并接收专用消息端口。读取/保存预设、预设变更事件、主题变量与输入法高度统一经过该消息通道。除明确点击「保存回酒馆」外，iframe 逻辑不会写入或刷新酒馆预设管理器。

纯功能回归测试运行：`node --test`（自动发现 `tests/` 下的用例）。

## 主要功能

- **世界书工作台（v1.8.5）**：首页独立入口，两侧分别导入本地世界书、读取酒馆世界书或新建空书。未展开详情即可按原生风格调整标题、触发策略、插入位置、深度、顺序、触发概率，并可编辑内容、复制/删除；列表上方显示对应设置名，禁用的深度不显示内容。关键词与可选过滤器使用逗号输入。支持正文/配置差异、搜索筛选、自选两条正文对比与编辑保存、鼠标拖拽与手机长按拖拽、排序，以及顶部图标统一撤回两侧。预设条目可从「预设」转换并插入世界书，默认常驻并保留原条目开关。修改先留在草稿，点击保存写回原书，另存创建新书，也可导出 JSON。
- **世界书条目缝合（v1.7.6）**：在目标侧搜索栏旁点击「世界书」，导入一份或多份世界书 JSON，或读取酒馆世界书列表，选书后立即显示条目。支持搜索、状态筛选、全选筛选结果及展开正文预览。每个选中条目转换为独立预设条目，提供「注入预设最前」「注入预设末尾」「注入指定位置」三个按钮，整批操作可一次撤回；结果仅写入当前侧草稿，仍需点击「保存」或「导出」。
- **双版本对比**：左侧显示旧版预设，右侧显示新版预设；先按 ID、相同正文、正文相似度与名称建立一对一关系，再以正文是否一致判定「内容相同 / 内容已修改」，避免 ID、名称或其他设置差异冒充正文修改；候选接近或证据不足时不自动配对。
- **语义化差异高亮**：英文等空格分词正文按完整单词和标点标注差异，不再把一个单词拆成零散字母；中文等无空格正文仍保留精确字符标注。配对修改行采用 VS Code 式浅红/浅绿底色帮助判断同行，真正变化的词或字符使用更深色块；「正文差异」开关控制高亮显示。
- **启用状态可视化**：条目自带酒馆原生风格的启用/禁用开关，点击即切换，并同步写入酒馆实际使用的 `prompt_order` 节点；禁用条目整行灰化，一眼区分；切换状态不会计入「已修改」。
- **导入与导出**：支持导入本地 `.json` 预设，也可以从酒馆当前可用的 OpenAI / Chat Completion 预设中选择载入；编辑后可导出新的 JSON 文件。
- **保存回酒馆**：对「酒馆预设」载入的一侧，可用「保存」按钮把改动直接写回酒馆预设本体；保存走酒馆原生 preset-manager 路径（不依赖酒馆助手），并监听酒馆原生事件，预设文件被外部修改时前端自动同步。保存前会先比对酒馆预设管理器当前选中的预设：同名才触发「重新应用刷新」，不同名只静默写盘，不会把酒馆当前活动预设切到被保存的预设。
- **条目搜索与筛选**：按名称、identifier 或正文搜索，并按差异状态、已拖拽、已手动修改等条件筛选。展开正文后按该侧搜索词高亮命中内容，不区分大小写；支持与正文差异同时显示。修改或清空搜索词只更新高亮，不丢失正在编辑的正文。
- **条目详情与编辑**：点击条目即可展开两版本的详细对比，查看并编辑名称、角色、触发条件、注入位置、深度、顺序和正文。
- **迁移与覆盖**：支持将缺失条目迁移到另一版本，并尽量保持目标列表中的对应位置；覆盖已有条目时，立即复制来源编辑框中的正文，不弹确认、不自动保存，需手动点击目标侧的「保存旧版条目 / 保存新版条目」。
- **正则对比、分组与拖拽迁移**：顶部「多选」旁只有一个紧凑的「正则」入口；读取两份预设的 `extensions.regex_scripts`，优先按 ID、再按两侧唯一同名正则配对，标出相同、配置有差异、新增和缺失；卡片默认只显示名称、状态与操作，点击左侧展开符号后按酒馆原生正则的层级查看查找式、替换内容和其他完整配置。支持单条迁移、勾选多条后点击「迁移所选」，也支持拖动任意已选正则，将整批按显示顺序放到另一版本、指定分组或同侧新位置；手机长按后拖动。兼容 BaiBai Tools 的 `extensions.baibaiToolkit.regexGroups` 数据，迁移时同步维护分组归属与组内顺序，并可撤回。
- **拖拽排序**：可在同一版本内调整顺序，也可将条目拖到另一版本；支持拖入已有分组；即使后续分组已折叠或被筛选隐藏，放到分组最后一条之后也会保持在该分组尾部，不会跳到整个预设末尾；每个条目带复制/删除按钮，副本紧跟原条目下方，且自动继承原条目的分组归属。
- **多选批量拖拽**：开启「多选」开关后点击条目即选中，拖动任意选中行即可整批迁移、重排、跨版本复制或入组；跨版本拖拽时逐条保持来源侧显示的开关状态，整批操作只记一条撤回历史，一次撤回全部恢复。
- **变量预设管理**：「获取变量」面板自动识别预设中的变量总条目，可直接编辑条目原文；检测其他条目已设置但总条目未收录的变量并可一键写入；检测被 `getvar` 引用但从未定义的变量并可补写；「引用变量」视图列出从未被读取的变量并在原文中高亮标注。
- **分组兼容**：兼容白白工具的预设条目分组数据。只有检测到实际分组时才使用分组排序；未使用分组功能的预设会保持 JSON 中 `prompts` 的原始位置。分组标题可点击折叠/展开，标题旁实时显示组内条目数。
- **项目保存**：可将两份预设、筛选条件、拖拽记录和手动修改记录保存为本地项目，方便分阶段处理；项目名称输入框点击即可从已保存项目中选择加载或删除。
- **撤回操作**：支持撤回最近的编辑、迁移或排序操作；多选批量拖拽会作为一次完整操作共同撤回。
- **配色切换**：自适应 / 日间 / 夜间三套配色一键切换（夜间为 Gruvbox Dark），选择会被记住。

## 使用流程

1. 打开插件，在“旧版预设”和“新版预设”区域分别导入 JSON，或点击“酒馆预设”从当前酒馆配置中选择。
2. 使用搜索框和筛选器定位新增、删除或修改的条目。
3. 点击条目查看两版本内容；需要同步时，使用“迁移”或“覆盖”按钮。覆盖后检查正文，再点击目标侧的「保存旧版条目 / 保存新版条目」提交；未保存即关闭或切换条目会丢弃该正文草稿。
4. 需要同步正则时点击顶部「多选」旁的“正则”，在对比面板中点击迁移，或勾选多条后点击「迁移所选」；拖动任意已选行可将整批放到另一版本／目标分组的指定位置；需要调整条目顺序时也可在同侧拖拽。
5. 完成后点击对应版本的“导出”；酒馆载入的一侧也可直接「保存」写回。
6. 处理时间较长时，可以先保存项目，之后再继续。

## PC 端适配

- 采用左右双栏布局，旧版和新版可以同时浏览。
- 两侧列表分别滚动，顶部工具栏包含导入、导出、搜索和筛选功能。
- 条目采用紧凑单行布局，隐藏名称下方的灰色 ID，保留名称、开关、操作按钮及差异标签；ID 仍保存在预设数据中并可用于搜索，但不占用对比详情空间。
- 对比详情在列表下方展开，两个版本的字段并排显示，适合大屏逐项核对。
- 支持鼠标拖拽排序、跨版本迁移和分组操作。

## 世界书缝合说明

v1.7.6 提供三个插入位置按钮，指定位置回到预设对比界面点击条目后选择插入之前或之后；继续兼容 HTTP 酒馆和旧版 WebView。

1. 先在旧版或新版一侧导入目标预设，再点击该侧「世界书」。
2. 添加本地世界书 JSON，或点击「酒馆世界书」读取列表，选择后立即显示该书条目。切换酒馆世界书会替换此前的酒馆来源，本地文件来源保留；每本书优先使用 `displayIndex` 顺序，无显示序号时保留文件顺序。
3. 读取后默认选中全部条目；可取消选择后逐条勾选，或搜索/筛选后点击「全选筛选结果」。筛选不清除此前的选择。点击条目名称展开正文。
4. 默认保留禁用状态。点击「注入预设最前」或「注入预设末尾」立即写入这一侧草稿；点击「注入指定位置」回到对比界面，在目标侧点击已注入条目，再选「插入之前」或「插入之后」。支持展开分组、搜索定位；「返回世界书」或 Esc 会返回面板并保留勾选。重复缝合生成独立新条目，不会按同名覆盖。
5. 指定位置时继承目标条目的有效分组；前/末插入沿用首/尾条目的分组，边界条目未分组时新条目也不分组。组尾之后仍在原组，折叠或筛选不会改变实际插入顺序。一次撤回同时恢复条目、顺序和分组。
6. 原样保留正文（含宏、换行、空白和空正文）、名称及可识别角色；开关同时写入条目和目标 `prompt_order` 节点。来源世界书不被修改。

世界书关键词、概率、递归、预算、原注入位置/深度等条件不会转换为预设触发逻辑。新条目统一采用预设相对位置，由预设列表顺序和开关控制；需要深度注入时可在缝合后编辑条目设置。为避免重复注入同样内容，请自行检查仍启用的来源世界书。支持标准世界书 `entries` 对象/数组及 JSON 角色卡的 `character_book.entries`；酒馆助手脚本 JSON 是参考代码，不是世界书数据。

核心转换位于 `src/worldbook.js`，选择面板位于 `src/ui/worldbook-panel.js`，对比列表选点模式位于 `src/ui/worldbook-placement.js`，酒馆读取统一通过 `src/host.js` 调用官方 `world-info.js` 的 `world_names` / `loadWorldInfo`，不依赖酒馆助手。

## 移动端适配

- 自动切换为上下布局：旧版区域在上，新版区域在下。
- 两个预设列表各自独立滚动，不会因为旧版条目较多而把新版导入按钮推到页面底部。
- 手机和平板条目采用单行布局：隐藏名称下方的灰色 identifier，保留名称、启用开关、复制/删除和差异标签，一屏可浏览更多条目；ID 仍保存在数据中并可搜索，但不占用对比详情空间。
- 预设面板头部单行紧凑显示：标题、预设文件名与导入、导出、酒馆预设、保存等按钮同一行，超长文件名省略号截断，操作按钮为小尺寸图标样式；「酒馆预设」在手机上缩略显示为「酒馆」。
- 五个功能开关胶囊与一个紧凑「正则」按钮在手机上单行排列，占位极小。
- 在条目或分组标题上滑动时，滚动的是对应的预设条目列表，列表边界不再把手势传给外层；在列表空白区域上滑时，可以继续推动整个插件界面，查看下方更多新版条目或对比详情。
- 支持移动端长按条目后拖拽排序；普通上下滑动仍用于浏览列表。拖拽已屏蔽系统原生拖拽会话，不会触发手机自带的跨应用传送功能（如一加「内容传送门」），拖到屏幕底部或边缘也不会跳出酒馆界面。拖拽中把指针停在列表上/下边缘约半秒即自动滚动该列表（越靠边越快），可把条目拖到当前视窗之外的位置；快速划过或跨窗口移动不会误触发，手指离开列表视区立即停止滚动。
- **输入法适配（假拼接）**：聚焦编辑控件时冻结视窗高度，扩选、复制粘贴时视角稳定不跳；键盘弹出时在内容末尾垫上与键盘等高的空白占位，页面可滚到底、输入法就像拼接在前端下方、完全不遮挡；键盘收起占位消失。键盘高度四通道检测，兼容 TauriTavern 与原生酒馆（普通浏览器）。

## 顺序读取规则

插件会根据预设中的 `prompt_order` 角色节点选择完整顺序：优先使用 `character_id: 100001`；没有该节点时，自动选择覆盖条目最多的顺序节点。对于未使用分组功能、且排序节点不完整的预设，未列入排序节点的条目会按 `prompts` 原始顺序补齐，避免条目位置错乱。

#### 设置快照怎么用

1. 在酒馆中调好预设条目及分组开关、世界书和正则，打开「酒馆盒子 → 设置快照」，在「当前设置」中点击「保存当前设置」。也可点击「创建快照」在独立页面搭配设置。
2. 点击「应用」随时切换；如果预设不同，会先切到快照记录的预设，酒馆原生的预设参数也会随之加载。
3. 需要自动切换时，点击「绑定此聊天」或「绑定此角色」。绑定本身不立即应用，当前要使用时再点「应用」。手动应用不会修改绑定；下次进入聊天再按绑定恢复。
4. 名称旁图标可重命名或删除；点击「查看快照详情」查看和修改设置。编辑后点击「保存」，选择「覆盖当前快照」或「另存为一个新的快照」；覆盖后，已有绑定引用更新后的配置。
5. 选择预设后展开条目窗口，可分别调整条目自身与分组总开关；关闭预设分组不改写成员自身开关。正则组与柏宝箱保持一致，组开关批量切换组内正则；部分开启时显示混合状态，也可逐条调整。

快照不备份预设/世界书正文，也不恢复条目顺序或分组归属。预设条目和正则按稳定 ID、世界书条目按 UID 恢复；新增条目保留当前状态，缺失条目会提示。预设整体改名后需更新快照。缺失世界书时，手动应用可选择是否继续，自动应用会停止并提示。世界书只保存全局挂载及这些书的条目配置，角色附加、聊天附加、角色主书和用户设定世界书均不在快照范围。

世界书条目配置写回共享世界书文件，会影响所有引用该书的位置；角色正则开关写回当前角色数据。正则只更改已有脚本的开关，不替换表达式，也不更改原生的角色/预设正则启用授权。已有聊天消息的正则显示需刷新聊天后更新，快照不会自动重载聊天。

旧快照应用时同样保留当前角色附加与聊天附加世界书；旧快照中的附加挂载不再恢复。没有资源配置的更早快照仍只恢复预设开关和全局挂载，首次编辑时从当前设置补齐新配置并提示检查。

快照库和角色绑定随酒馆设置保存，聊天绑定随聊天元数据保存。删除快照会使对应聊天绑定失效；若角色仍有有效默认绑定，下次进入聊天会回退到角色默认。群聊可绑定当前聊天，不自动选择某位群成员的角色默认快照。

预设开关和预设正则应用于当前运行配置，不主动覆盖预设文件；柏宝箱自身已存在的保存任务仍按它的保存机制执行。自动应用会更改酒馆当前全局设置，而非为不同聊天同时维持各自独立的运行配置。世界书原生编辑仍有未保存修改时会等待其保存，无法确认时停止；资源保存失败会提示并尝试恢复之前的配置。

### 1.7.0 更新

以下为 1.6.2 之后新增与修复的全部内容。

#### 新增功能

- **变量预设管理**：新增「获取变量」面板，管理预设中的 `{{setvar}}` / `{{getvar}}` 变量宏。
  - 自动识别获取变量总条目（收录 setvar 最多的条目），顶部显示条目名与保存图标，条目原文可直接编辑并保存写回，支持撤回。
  - **未收录检测**：找出其他条目已设置、但总条目没有收录的变量，逐行列出变量名、来源条目名与引用次数，可一键把空值宏 `{{setvar::变量名:: }}` 追加写入总条目末尾。
  - **未定义检测**：列出被 `getvar` 引用但全预设从未定义的变量，可一键补写空值宏。
  - **引用变量视图**：锁定获取变量总条目，列出其中从未被 `getvar` 读取的变量——橘红色标签一目了然，条目原文内对应 `{{setvar}}` 宏整段高亮标注，编辑时实时重绘；可保存写回并撤回。
  - 未注入（未进入有效 `prompt_order`）的条目不参与变量检测，避免干扰统计。
- **多选批量拖拽**：头部新增「多选」开关，开启后点击条目即选中（绿色描边高亮），拖动任意选中行即可整批移动；同侧拖拽为批量重排、跨版本拖拽为批量复制（源侧保留）、拖到白白工具分组标题上为批量入组。桌面 HTML5 拖拽、指针拖拽与移动端长按拖拽三条路径全部支持，整批操作只记一条撤回历史，一次撤回全部恢复。
- **开关胶囊化**：自由选择、忽略空白、正文差异、差异程度、多选五个开关改为无方形勾选框的胶囊按钮，选中整颗高亮，深浅主题下均清晰可读。
- **头部紧凑化**：项目名称输入框点击弹出已保存项目下拉，可直接选择加载或删除；加载 / 保存 / 删除改为图标按钮；主题切换与关闭按钮收进头部；撤回按钮 PC 端位于主标题旁，平板 / 手机位于「旧版预设」标题旁。
- **三档响应式头部**：PC（≥901px）/ 平板（521~900px）/ 窄屏手机（≤520px）分别适配，五个开关胶囊在各档位均保持单行，项目栏与标题行不再挤占列表空间。
