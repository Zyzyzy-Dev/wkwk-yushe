# 预设更新编辑器

这是一个用于 SillyTavern OpenAI / Chat Completion 预设的对比和迁移插件。它可以同时载入旧版与新版预设，快速查看条目差异，并将条目或修改后的内容迁移到另一版本。

## 主要功能

- **双版本对比**：左侧显示旧版预设，右侧显示新版预设；每条预设会标记为相同、已修改、新增或删除。
- **字符级差异高亮**：正文对比精确到字符，只标记真正变化的字符而非整行标红；「正文差异」开关控制高亮显示。
- **启用状态可视化**：条目自带酒馆原生风格的启用/禁用开关，点击即切换，并同步写入酒馆实际使用的 `prompt_order` 节点；禁用条目整行灰化，一眼区分；切换状态不会计入「已修改」。
- **导入与导出**：支持导入本地 `.json` 预设，也可以从酒馆当前可用的 OpenAI / Chat Completion 预设中选择载入；编辑后可导出新的 JSON 文件。
- **保存回酒馆**：对「酒馆预设」载入的一侧，可用「保存」按钮把改动直接写回酒馆预设本体；保存走酒馆原生 preset-manager 路径（不依赖酒馆助手），并监听酒馆原生事件，预设文件被外部修改时前端自动同步。
- **条目搜索与筛选**：按名称、identifier 或正文搜索，并按差异状态、已拖拽、已手动修改等条件筛选。
- **条目详情与编辑**：点击条目即可展开两版本的详细对比，查看并编辑名称、角色、触发条件、注入位置、深度、顺序和正文。
- **迁移与覆盖**：支持将条目从旧版迁移到新版，或用一版内容覆盖另一版；迁移时会尽量保持目标列表中的对应位置。
- **拖拽排序**：可在同一版本内调整顺序，也可将条目拖到另一版本；支持拖入已有分组；每个条目带复制/删除按钮。
- **分组兼容**：兼容白白工具的预设条目分组数据。只有检测到实际分组时才使用分组排序；未使用分组功能的预设会保持 JSON 中 `prompts` 的原始位置。
- **项目保存**：可将两份预设、筛选条件、拖拽记录和手动修改记录保存为本地项目，方便分阶段处理。
- **撤回操作**：支持撤回最近的编辑、迁移或排序操作。

## 使用流程

1. 打开插件，在“旧版预设”和“新版预设”区域分别导入 JSON，或点击“酒馆预设”从当前酒馆配置中选择。
2. 使用搜索框和筛选器定位新增、删除或修改的条目。
3. 点击条目查看两版本内容；需要同步时，使用“迁移”或“覆盖”按钮。
4. 需要调整顺序时直接拖拽条目，完成后点击对应版本的“导出”；酒馆载入的一侧也可直接「保存」写回。
5. 处理时间较长时，可以先保存项目，之后再继续。

## PC 端适配

- 采用左右双栏布局，旧版和新版可以同时浏览。
- 两侧列表分别滚动，顶部工具栏包含导入、导出、搜索和筛选功能。
- 对比详情在列表下方展开，两个版本的字段并排显示，适合大屏逐项核对。
- 支持鼠标拖拽排序、跨版本迁移和分组操作。

## 移动端适配

- 自动切换为上下布局：旧版区域在上，新版区域在下。
- 两个预设列表各自独立滚动，不会因为旧版条目较多而把新版导入按钮推到页面底部。
- 条目行采用紧凑布局：条目名称与启用开关并排显示，每条目仅占两行高，一屏可浏览更多条目。
- 在条目或分组标题上滑动时，滚动的是对应的预设条目列表；在列表空白区域上滑时，可以继续推动整个插件界面，查看下方更多新版条目或对比详情。
- 压缩标题栏、按钮和筛选控件，保留导入、酒馆预设、保存、导出、搜索和筛选等主要操作。
- 支持移动端长按条目后拖拽排序；普通上下滑动仍用于浏览列表。拖拽已屏蔽系统原生拖拽会话，不会触发手机自带的跨应用传送功能（如一加「内容传送门」），拖到屏幕底部或边缘也不会跳出酒馆界面。拖拽中把指针停在列表上/下边缘约半秒即自动滚动该列表（越靠边越快），可把条目拖到当前视窗之外的位置；快速划过或跨窗口移动不会误触发，手指离开列表视区立即停止滚动。
- **输入法适配（假拼接）**：聚焦编辑控件时冻结视窗高度，扩选、复制粘贴时视角稳定不跳；键盘弹出时在内容末尾垫上与键盘等高的空白占位，页面可滚到底、输入法就像拼接在前端下方、完全不遮挡；键盘收起占位消失。键盘高度四通道检测，兼容 TauriTavern 与原生酒馆（普通浏览器）。

## 顺序读取规则

插件会根据预设中的 `prompt_order` 角色节点选择完整顺序：优先使用 `character_id: 100001`；没有该节点时，自动选择覆盖条目最多的顺序节点。对于未使用分组功能、且排序节点不完整的预设，未列入排序节点的条目会按 `prompts` 原始顺序补齐，避免条目位置错乱。

## 当前版本

`1.4.0`

### 1.4.0 更新

- 恢复 1.3.0 中因网页上传未同步而被覆盖丢失的触屏修复：触屏设备全程禁用行级 content-visibility（修复拖拽开始瞬间行高突变导致的视角下滑错位、拖到边缘命中失真），桌面端保留该性能优化；新增交互锁——长按拖拽/桌面拖拽/编辑聚焦期间，酒馆自身或任意第三方插件触发的预设变更延迟到操作结束后统一同步，避免 DOM 重建打断操作；列表重建保持滚动位置，全新载入场景仍回到顶部；触屏拖拽松手落在分组标题/组内空白时归入该组末尾（而非整个列表末尾）。
- 新增拖拽自动滚动（Windows 文件管理器风格）：拖拽中指针靠近某列表上/下边缘即持续滚动该列表，越靠近边缘越快、滚到边界自停；边缘需停留约 0.45 秒才激活，快速划过、跨窗口移动不误触发；手指离开某列表视区立即停止其滚动；条目跨版本放置后源列表视角自动回到拖拽前。
- 新增「差异程度」开关（忽略空白旁）：开启后同名已修改条目显示正文差异百分比（如「差异 12%」），缝合更新时差异小的可放心忽略、差异大的重点核对是否为自己的魔改或作者的重要更新；开关状态持久化保留。
- 自由选择支持取消选中：再次点击已选中的旧版或新版条目即取消选择，误点可撤销。
- 移动端旧版预设可见空间放大（手机 44dvh / 平板 42dvh）；编辑工作区紧凑化——姓名/身份/触发器/位置四字段横排压缩、编辑器内边距收窄、「保存旧版/新版条目」按钮降高并保持整行右对齐。

### 1.3.0 更新

- 启用/禁用改为酒馆原生风格的可视化开关，与条目名称并排显示；禁用条目整行灰化；切换启用状态不再给条目误挂「已修改」标签。
- 修复使用「仿短信·粉（改布局）」等美化主题时，开启正文差异会导致对比区显示空白的问题（正文差异原有功能不变）。
- 移动端条目行更紧凑：名称与开关并排，每条目两行高，一屏可见更多条目。
- 分组预设体验优化：手指按在分组标题上滑动时，滚动的是该侧预设条目列表，不再带动整个插件界面；列表空白处滑动仍可推动整个界面。
- 长按拖拽不再触发手机系统的跨应用传送功能（如一加「内容传送门」）：触摸进行中屏蔽系统原生拖拽，条目行禁止长按选中，拖到屏幕底部/边缘不会再跳出酒馆。
- 移动端/平板拖拽与分组稳定性：长按拖拽按触摸点身份追踪，第二根手指误触其他条目不会抢走拖拽；分组预设上切换启用/禁用开关时界面保持原位不跳动；跨版本拖拽条目到分组预设后立即出现在指定位置，无需再操作一步触发刷新。

### 1.2.0 更新

- 每个预设面板新增「保存」按钮：把该侧改动写回酒馆预设本体，走酒馆原生 `preset-manager` 的 `savePreset`/`updateList` 路径（不依赖酒馆助手）；保存后前端自动刷新，并监听酒馆原生 `preset_changed` 事件——预设文件被外部修改时界面跟着变。本地 JSON 文件无法被浏览器原地覆盖，仍需用「导出」。
- 移动端输入法假拼接适配（见上文移动端说明）：视窗冻结防跳 + 键盘等高空白占位，TauriTavern 与原生酒馆双兼容。
- 「自由选择 / 忽略空白 / 正文差异」三个开关状态改用 IndexedDB 持久化，重开插件后保留。
- 提示改用轻量自绘 toast（替代酒馆原生 toastr，移动端更顺滑）。
- 移动端修复与性能：修复长按原地释放被误移到列表末尾（死区判定 + 松手最终判定 + 拖拽期间临时关闭 content-visibility 保证命中准确）；长按拖拽逐帧命中检测；自由选择改轻量标记；搜索输入 150ms 防抖；长列表行启用 content-visibility 跳过屏幕外渲染；首次差异高亮空闲执行。

### 1.1.0 更新

- 未进入有效 `prompt_order` 的条目不再隐藏，统一显示在列表底部的“未注入”分组中。
- 新增“自由选择”开关：开启后依次选择旧版条目和新版条目，可直接编辑两个不同 identifier 的条目。

### 1.0.1 更新

- 预设条目列表显示当前启用状态，点击“已启用/已禁用”标签即可切换。
- 启用状态会同步写入酒馆实际使用的 `prompt_order` 节点。
- 隐藏未注入当前预设的条目，只显示有效排序节点中的预设条目。
