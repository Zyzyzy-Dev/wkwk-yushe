# 预设条目对比、编辑与拖拽迁移

## 2.4.0

- 修复包含多个 `prompt_order` 角色节点的预设：优先使用 `character_id: 100001` 的完整顺序节点。
- 兼容只有单个顺序节点的普通预设，并按条目覆盖数量自动选择完整节点。
- 修复 `【Ako】1.91_SP_SillyAko（0801正确版）` 这类预设被错误读取前 11 个系统条目的问题。

## 2.3.9

- 修复未使用白白预设分组功能的预设：列表顺序现在严格保持导入 JSON 的 `prompts` 原始顺序，不再被不完整的 `prompt_order` 重排。
- 只有实际存在白白分组时，才使用分组预设的排序数据。

## 2.3.8

- 修复新版“酒馆预设”按钮仍写入旧版栏的问题。
- 移动端列表边界允许滚动链传递到插件外层，空白区域上滑可继续查看新版条目。

## 2.3.7

- 移动端旧版与新版区域固定上下排列，两个预设列表可分别滚动，便于随时对照相近条目。
- 新版预设标题与导入按钮不再被旧版长列表推到页面末尾。
- 收敛外层与列表滚动范围，消除上滑到底后出现的额外空白区域。

## 2.3.6

- 移除移动端外层底部额外空白，向上滑动不会进入虚假的空白区域。
- 移动端仍保持旧版在上、新版在下和各自独立的条目滚动。
- 顺序缓存严格读取 prompt_order[0].order。
- prompt_order 中的条目按 order 顺序显示；未列入 order 的条目按原 prompts 顺序追加，避免遍历其他 order 结构造成乱序。
