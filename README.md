# 预设更新编辑器

这是一个用于 SillyTavern OpenAI / Chat Completion 预设的对比和迁移插件。它可以同时载入旧版与新版预设，快速查看条目差异，并将条目或修改后的内容迁移到另一版本。

## 主要功能

- **双版本对比**：左侧显示旧版预设，右侧显示新版预设；先按 ID、相同正文、正文相似度与名称建立一对一关系，再以正文是否一致判定「内容相同 / 内容已修改」，避免 ID、名称或其他设置差异冒充正文修改；候选接近或证据不足时不自动配对。
- **语义化差异高亮**：英文等空格分词正文按完整单词和标点标注差异，不再把一个单词拆成零散字母；中文等无空格正文仍保留精确字符标注。配对修改行采用 VS Code 式浅红/浅绿底色帮助判断同行，真正变化的词或字符使用更深色块；「正文差异」开关控制高亮显示。
- **启用状态可视化**：条目自带酒馆原生风格的启用/禁用开关，点击即切换，并同步写入酒馆实际使用的 `prompt_order` 节点；禁用条目整行灰化，一眼区分；切换状态不会计入「已修改」。
- **导入与导出**：支持导入本地 `.json` 预设，也可以从酒馆当前可用的 OpenAI / Chat Completion 预设中选择载入；编辑后可导出新的 JSON 文件。
- **保存回酒馆**：对「酒馆预设」载入的一侧，可用「保存」按钮把改动直接写回酒馆预设本体；保存走酒馆原生 preset-manager 路径（不依赖酒馆助手），并监听酒馆原生事件，预设文件被外部修改时前端自动同步。
- **条目搜索与筛选**：按名称、identifier 或正文搜索，并按差异状态、已拖拽、已手动修改等条件筛选。
- **条目详情与编辑**：点击条目即可展开两版本的详细对比，查看并编辑名称、角色、触发条件、注入位置、深度、顺序和正文。
- **迁移与覆盖**：支持将缺失条目迁移到另一版本，并尽量保持目标列表中的对应位置；覆盖已有条目时，立即复制来源编辑框中的正文，不弹确认、不自动保存，需手动点击目标侧的「保存旧版条目 / 保存新版条目」。
- **拖拽排序**：可在同一版本内调整顺序，也可将条目拖到另一版本；支持拖入已有分组；即使后续分组已折叠或被筛选隐藏，放到分组最后一条之后也会保持在该分组尾部，不会跳到整个预设末尾；每个条目带复制/删除按钮，副本紧跟原条目下方，且自动继承原条目的分组归属。
- **多选批量拖拽**：开启「多选」开关后点击条目即选中，拖动任意选中行即可整批迁移、重排、跨版本复制或入组；跨版本拖拽时逐条保持来源侧显示的开关状态，整批操作只记一条撤回历史，一次撤回全部恢复。
- **变量预设管理**：「获取变量」面板自动识别预设中的变量总条目，可直接编辑条目原文；检测其他条目已设置但总条目未收录的变量并可一键写入；检测被 `getvar` 引用但从未定义的变量并可补写；「引用变量」视图列出从未被读取的变量并在原文中高亮标注。
- **分组兼容**：兼容白白工具的预设条目分组数据。只有检测到实际分组时才使用分组排序；未使用分组功能的预设会保持 JSON 中 `prompts` 的原始位置。分组标题可点击折叠/展开，标题旁实时显示组内条目数。
- **项目保存**：可将两份预设、筛选条件、拖拽记录和手动修改记录保存为本地项目，方便分阶段处理；项目名称输入框点击即可从已保存项目中选择加载或删除。
- **撤回操作**：支持撤回最近的编辑、迁移或排序操作；多选批量拖拽会作为一次完整操作共同撤回。
- **配色切换**：自适应 / 日间 / 夜间三套配色一键切换（夜间为 Gruvbox Dark），选择会被记住。

## 使用流程

1. 打开插件，在“旧版预设”和“新版预设”区域分别导入 JSON，或点击“酒馆预设”从当前酒馆配置中选择。
2. 使用搜索框和筛选器定位新增、删除或修改的条目。
3. 点击条目查看两版本内容；需要同步时，使用“迁移”或“覆盖”按钮。覆盖后检查正文，再点击目标侧的「保存旧版条目 / 保存新版条目」提交；未保存即关闭或切换条目会丢弃该正文草稿。
4. 需要调整顺序时直接拖拽条目，完成后点击对应版本的“导出”；酒馆载入的一侧也可直接「保存」写回。
5. 处理时间较长时，可以先保存项目，之后再继续。

## PC 端适配

- 采用左右双栏布局，旧版和新版可以同时浏览。
- 两侧列表分别滚动，顶部工具栏包含导入、导出、搜索和筛选功能。
- 条目采用紧凑单行布局，隐藏名称下方的灰色 ID，保留名称、开关、操作按钮及差异标签；ID 仍保存在预设数据中并可用于搜索，但不占用对比详情空间。
- 对比详情在列表下方展开，两个版本的字段并排显示，适合大屏逐项核对。
- 支持鼠标拖拽排序、跨版本迁移和分组操作。

## 移动端适配

- 自动切换为上下布局：旧版区域在上，新版区域在下。
- 两个预设列表各自独立滚动，不会因为旧版条目较多而把新版导入按钮推到页面底部。
- 手机和平板条目采用单行布局：隐藏名称下方的灰色 identifier，保留名称、启用开关、复制/删除和差异标签，一屏可浏览更多条目；ID 仍保存在数据中并可搜索，但不占用对比详情空间。
- 预设面板头部单行紧凑显示：标题、预设文件名与导入、导出、酒馆预设、保存等按钮同一行，超长文件名省略号截断，操作按钮为小尺寸图标样式；「酒馆预设」在手机上缩略显示为「酒馆」。
- 五个功能开关胶囊（自由选择、忽略空白、正文差异、差异程度、多选）在手机上单行排列，占位极小。
- 在条目或分组标题上滑动时，滚动的是对应的预设条目列表，列表边界不再把手势传给外层；在列表空白区域上滑时，可以继续推动整个插件界面，查看下方更多新版条目或对比详情。
- 支持移动端长按条目后拖拽排序；普通上下滑动仍用于浏览列表。拖拽已屏蔽系统原生拖拽会话，不会触发手机自带的跨应用传送功能（如一加「内容传送门」），拖到屏幕底部或边缘也不会跳出酒馆界面。拖拽中把指针停在列表上/下边缘约半秒即自动滚动该列表（越靠边越快），可把条目拖到当前视窗之外的位置；快速划过或跨窗口移动不会误触发，手指离开列表视区立即停止滚动。
- **输入法适配（假拼接）**：聚焦编辑控件时冻结视窗高度，扩选、复制粘贴时视角稳定不跳；键盘弹出时在内容末尾垫上与键盘等高的空白占位，页面可滚到底、输入法就像拼接在前端下方、完全不遮挡；键盘收起占位消失。键盘高度四通道检测，兼容 TauriTavern 与原生酒馆（普通浏览器）。

## 顺序读取规则

插件会根据预设中的 `prompt_order` 角色节点选择完整顺序：优先使用 `character_id: 100001`；没有该节点时，自动选择覆盖条目最多的顺序节点。对于未使用分组功能、且排序节点不完整的预设，未列入排序节点的条目会按 `prompts` 原始顺序补齐，避免条目位置错乱。

### 1.7.4 更新

本次将英文整词差异、详情精简与配对同行底色统一为 **1.7.4**，保留全部功能代码，不回退修复。

- **英文正文按单词标注**：配对行内的英文、数字及连字符词按完整单词比较，标点独立比较，不再把单词拆成单个字母着色；长句改写时可直接看出增删了哪些词。
- **中文精度保持不变**：中文、日文、韩文等无空格文字继续逐字比较，混合中英文正文会自动在单词级与字符级之间切换，不牺牲原有精确度。
- **对比详情更紧凑**：移除条目标题下方的 identifier / UUID 信息行，ID 仍保存在预设数据中并可参与搜索与匹配，不会修改或丢失原始数据。
- **恢复配对同行底色**：正文差异中的成对修改行重新显示浅红/浅绿整行底色，便于像 VS Code 一样快速判断左右内容是否属于同一行。
- **保持两级差异强度**：同行底色使用低透明度，只负责提示行对应关系；真正删除或新增的单词/字符继续用更深色块标注。完整新增或删除的非配对行仍保留原有较强整行底色。
- **三套配色统一**：自适应、日间和夜间主题分别使用对应的低透明度红绿底色，桌面与手机采用相同规则；英文仍按完整单词比较，中文仍按字符精确比较。

### 1.7.3 更新

本次将近期正文对比、分组拖拽与引用变量界面修复统一为 **1.7.3**，保留全部功能代码，不回退修复。

- **引用变量说明消歧**：引用变量界面始终显示「有 X 个变量已经定义但未被引用」，包括 X 为 0 的情况；不再用“这些变量”泛指，也不再把简略计数塞在条目名称后面。
- **列表与正文标注保持一致**：存在未引用变量时，界面直接列出变量名，并继续在获取变量条目原文中用橘红色标注对应的 `setvar / setglobalvar` 宏；不存在时显示 0 个且不展示空列表或误导性说明。变量名按去除首尾空格后的名称去重。
- **分组尾部拖拽定位修正**：拖到某个分组最后一个条目之后时，落点改为按目标预设的完整顺序计算，不再依赖下一个当前可见条目。后续分组折叠、被搜索/筛选隐藏时，跨版本拖拽仍会落在指定分组尾部，而不是整个预设最底部。
- **三套拖拽路径统一**：桌面 HTML5 拖拽、Windows/触控笔指针拖拽和手机长按拖拽共用同一顺序锚点；多选拖拽会跳过正在移动的条目，避免把自身误当作落点。
- **正文优先判定标签**：条目配对仍优先保留同 ID，并继续支持跨 ID 的相同/相似正文匹配；配对完成后，「内容相同 / 内容已修改」只由正文决定。正文完全一致时，即使 ID、名称、身份、触发器或其他条目设置不同，也显示「内容相同」；这些设置仍可在详情编辑区分别查看和修改。
- **手机端差异高亮修正**：配对修改行与完整新增/删除行使用不同强度的底色，真正变化的字符使用更深色块。自 1.7.4 起，配对行恢复低透明度浅红/浅绿同行底色，桌面、平板和手机采用同一规则。
- **真实预设回归**：小冰块 V3.81 与神本无相 V0.5 中正文完全一致的 Claude 头部条目现在稳定显示「内容相同」，不同 ID 和名称不会改变正文标签。

### 1.7.2 更新

本次将近期跨 ID 正文匹配与相似正文匹配更新统一为 **1.7.2**，保留全部修复功能，不回退代码。

- **重新缝合条目准确对比**：修复重新创建后 ID 不同的条目被误报为「新版新增 / 新版已删除」的问题。先保留同 ID 对应关系，再对非空相同正文进行一对一匹配；重复正文仅在名称或剩余候选能唯一对应时配对。
- **正文略有修改也能对应**：对剩余条目进一步结合正文相似度与名称判断。例如小冰块 V3.81 与神本无相 V0.5 中的「锦绣灰堆」「苦杏仁」「气泡水」「金鱼灯」，可自动配对为「内容已修改」，实际差异继续保留。
- **多重依据与歧义保护**：相似匹配按连续三个字符及出现次数计算正文相似度；同名至少 82%，改名或无名称至少 92%，并要求双方互为最佳候选、各自领先次优候选至少 6 个百分点。名称只作为辅助依据；空正文、少于 32 字符或字符片段过于单一的正文不参与相似匹配。无法可靠区分的模板/副本留给「自由选择」手动比较。该匹配分数与列表原有「差异程度」显示算法不同。
- **标签、统计与详情统一**：跨 ID 配对同时用于差异标签、数量统计、筛选、差异程度及双侧详情，并提示「按正文匹配（ID 不同）」或「按相似正文匹配（ID 不同，请核对差异）」。原始 ID 仍保存在数据中并参与搜索与匹配，但自 1.7.4 起不再占用详情标题空间；顺序、分组或启用状态不会被修改。自 1.7.3 起，标签改为正文优先，名称、身份、注入设置等元数据差异不再标为「内容已修改」。
- **覆盖与编辑联动**：跨 ID 条目可双向覆盖正文，仍只更新编辑框草稿、手动保存目标侧。当前载入的两份预设中，已建立的配对在编辑后继续保留，避免修改后重新变成新增/删除；支持保存、撤回及继续查看详情。
- **刷新与性能**：刷新不会因其他条目已匹配而把有歧义的候选逐步强行配对。长正文使用字符片段索引，内容和名称未变时复用计算结果，避免切换开关时重复扫描。
- **匹配边界**：开启「忽略空白」时，正文匹配同步忽略空白。重新导入、加载项目或切换「忽略空白」后按当前数据重新判断，相似度不足的条目仍可能需要手动比较。自动匹配记录不会写入导出的预设。跨版本拖拽仍按原有 ID 复制规则执行，不会因正文相同或相似而自动合并条目。

- **拖拽保持开关状态**：修复单条及多选跨版本拖拽后，目标开关偶尔与来源不一致的问题。迁移以来源侧实际显示的开关为准，源侧保持不变；拖入分组、目标已有同 ID 条目时同样生效。
- **排序与撤回更稳定**：同侧重排不再意外改变开关；兼容字符串形式的排序项，更新开关时不会重复插入同 ID。批量拖拽及入组仍可一次撤回，恢复原始数据与开关状态。

- **正文即时覆盖、手动保存**：「用旧版覆盖新版 / 用新版覆盖旧版」立即复制来源编辑框的正文（含未保存文字），不弹二次确认，也不自动保存；名称、身份、注入设置和启用状态不随正文覆盖改变。
- **两侧草稿独立保留**：点击对应的「保存旧版条目 / 保存新版条目」才提交该侧修改，支持撤回；保存一侧不再清空另一侧未保存的编辑。未保存即关闭或切换条目，会丢弃该正文草稿。
- **三端紧凑列表**：PC、平板和手机统一隐藏名称下方的灰色 ID 行，缩短条目高度，一屏可浏览更多条目；名称、开关、操作按钮和差异标签保留，ID 仍可搜索并在详情中查看。
- **手机头部压缩**：缩矮旧版/新版的标题、搜索及统计区域，把空间留给列表；两个列表继续独立滚动，PC、平板头部不变。
- **缺失条目迁移修复**：迁移后立即刷新缓存，新条目可正常显示并查看详情。

### 1.7.0 更新

以下为 1.6.2 之后新增与修复的全部内容。

#### 新增功能

- **变量预设管理**：新增「获取变量」面板，管理预设中的 `{{setvar}}` / `{{getvar}}` 变量宏。
  - 自动识别获取变量总条目（收录 setvar 最多的条目），顶部显示条目名与保存图标，条目原文可直接编辑并保存写回，支持撤回。
  - **未收录检测**：找出其他条目已设置、但总条目没有收录的变量，逐行列出变量名、来源条目名与引用次数，可一键把空值宏 `{{setvar::变量名:: }}` 追加写入总条目末尾。
  - **未定义检测**：列出被 `getvar` 引用但全预设从未定义的变量，可一键补写空值宏。
  - **引用变量视图**：锁定获取变量总条目，列出其中从未被 `getvar` 读取的变量——橘红色标签一目了然，条目原文内对应 `{{setvar}}` 宏整段高亮标注，编辑时实时重绘；可保存写回并撤回。
  - 未注入（未进入有效 `prompt_order`）的条目不参与变量检测，避免干扰统计。
- **多选批量拖拽**：头部新增「多选」开关，开启后点击条目即选中（绿色描边高亮），拖动任意选中行即可整批移动；同侧拖拽为批量重排、跨版本拖拽为批量复制（源侧保留）、拖到白白工具分组标题上为批量入组。桌面 HTML5 拖拽、指针拖拽与移动端长按拖拽三条路径全部支持，整批操作只记一条撤回历史，一次撤回全部恢复。
- **开关胶囊化**：自由选择、忽略空白、正文差异、差异程度、多选五个开关改为无方形勾选框的胶囊按钮，选中整颗高亮，深浅主题下均清晰可读。
- **头部紧凑化**：项目名称输入框点击弹出已保存项目下拉，可直接选择加载或删除；加载 / 保存 / 删除改为图标按钮；主题切换与关闭按钮收进头部；撤回按钮 PC 端位于主标题旁，平板 / 手机位于「旧版预设」标题旁。
